# LifeFlow

LifeFlow is a simple personal command center for tasks, spending, goals and habits.

## Beta
- Supabase email/password authentication
- Supabase database CRUD
- User-scoped data protected by RLS
- Responsive dashboard
- Static-hosting ready

## Deployment
Publish the repository as a static site, then configure Supabase Auth Site URL and Redirect URLs to the final public URL.

AI and payments are separate next-stage services.
